# 自定义右键动作

从菜单栏打开「我的动作…」，把 Python 或 Shell 脚本保存成 Finder 菜单项。
适用于图片处理、批量改名、文件整理，以及调用 `curl` / `ossutil` 等工具上传文件。

主窗口侧边栏在「我的动作」与「动作市场」之间切换。「我的动作」左侧是可搜索的动作列表，右侧显示所选动作的详情；未选择时右侧显示提示。列表右上角的「+」新建动作，「…」菜单包含复制动作、复制动作包、上移 / 下移和删除。「动作市场」以卡片网格展示，点击卡片打开详情弹窗。

## 创建、测试、保存

1. 点列表右上角的「+」（⌘N），创建空白动作。
2. 在「动作设置」中填写名称，选择图标、菜单分组、文件类型和单选 / 多选条件。
3. 在「脚本」中选择运行环境并编写代码，或选择一个外部脚本文件。外部文件在每次运行时读取最新内容。
4. 在「手动测试」中选择测试文件或文件夹，点「运行当前草稿」（⌘R）。
5. 查看标准输出、错误输出、退出码和耗时，确认后点「保存」（⌘S）。下一次右键会使用新配置。

**测试会真实执行脚本，包括修改文件、删除或上传。** 请用准备好的测试文件。
测试运行当前草稿，不会自动保存到 Finder。关闭窗口会保留草稿；切换动作或退出应用时会提示保存。

## 菜单、图标与显示条件

- 每个动作可以启用 / 停用（列表行内的开关或编辑器中的开关）、复制、删除；在列表中拖动或用 ⌘⌥↑ / ⌘⌥↓ 调整已保存动作的顺序。
- 分组留空时直接显示在「右键助手」下；相同分组的动作聚合到子菜单中。
  分组位置由该组第一个动作的位置决定，组内顺序跟随动作列表。
- 图标区显示当前图标，点击右侧「图标库」从 64 个内置图标中选择，支持文件、图片、办公、开发、网络和工具分类及名称搜索。市场导入的自定义图标会保留显示，也可从图标库替换。
- 可限定文件、文件夹、两者；文件可限定图片或扩展名，例如 `jpg, png, webp`。
  扩展名不区分大小写，也接受 `.jpg` / `*.jpg`。
- 所选项目必须全部满足条件，不会忽略不匹配的文件。文件类型条件只作用于文件。
- Finder 空白处右键时，把当前文件夹作为输入。停用的动作仍可以在编辑器中手动测试。

## Python 与 Shell 环境

Python 使用本机已安装的解释器。可以填写或选择虚拟环境中的完整路径，例如：

```text
/Users/yourname/.venvs/rightkit/bin/python
/opt/homebrew/bin/python3
```

留空会优先复用已创建的 `~/.venvs/rightkit` 环境，再搜索常用安装位置和 PATH；
自动搜索不会启动可能触发开发工具安装的 `/usr/bin/python3`。
也可以通过动作的 `VIRTUAL_ENV` 指定环境，它优先于默认 RightKit 环境；手动填写的解释器优先级最高。
RightKit 不内置 Python，也不会自动安装依赖。

使用 `PIL` 的图片脚本需要 Pillow。可以准备独立环境来安装依赖：

```sh
python3 -m venv ~/.venvs/rightkit
~/.venvs/rightkit/bin/python -m pip install Pillow
~/.venvs/rightkit/bin/python -c 'import sys; print(sys.executable)'
```

环境准备好后，Python 动作可以把「Python 解释器」留空，自动复用这个环境。
需要固定解释器时，把最后一条命令输出的完整路径填到动作「脚本」页的「Python 解释器」中，然后保存。
安装依赖和运行动作必须使用同一个 Python 环境。安装包名是 `Pillow`，代码中导入的模块名是 `PIL`。
出现 `No module named 'PIL'` 时，检查这个动作实际选择的解释器和 `VIRTUAL_ENV`，确认 Pillow 安装在对应环境中。

Shell 支持系统自带的 zsh、bash、sh，适合调用 `curl`、`ditto` 或本机安装的命令。
脚本不会加载交互式终端配置，标准输入为空，不能在运行途中要求输入密码。
默认 PATH 包含 `/opt/homebrew/bin`、`/usr/local/bin` 和系统命令目录；自定义 PATH 会覆盖它。

### Shell 通知示例

运行环境选择 Shell，在脚本中直接执行以下命令，可以请求 macOS 显示当前工作目录：

```sh
/usr/bin/osascript -e 'display notification (system attribute "PWD") with title "当前目录"'
```

前面加 `echo` 会把命令打印到标准输出，通知命令不会执行。
通知是否显示为右上角横幅还取决于 macOS 的通知设置和专注模式；退出码 0 表示命令执行成功。

## 输入约定

所选文件 / 文件夹的完整路径作为参数数组传入，路径不会拼进脚本内容。

Python：

```python
import sys
from pathlib import Path

for argument in sys.argv[1:]:
    path = Path(argument)
    print(path)
```

Shell：

```sh
set -eu
for input_path in "$@"; do
    printf '%s\n' "$input_path"
done
```

Shell 中仍需给变量加双引号，例如 `"$input_path"`，以保留空格和特殊字符。

| 环境变量 | 含义 |
| --- | --- |
| `RIGHTKIT_INPUTS_JSON` | 本次脚本调用的路径数组，JSON 字符串 |
| `RIGHTKIT_INPUT_COUNT` | 本次调用的输入数量 |
| `RIGHTKIT_CURRENT_DIRECTORY` | 本次工作目录 |
| `RIGHTKIT_CONTEXT_FILE` | 本次运行的 JSON 上下文文件路径，运行结束后删除 |

上下文文件示例：

```json
{
  "actionID": "动作 UUID",
  "paths": ["/Users/yourname/Pictures/example.png"],
  "allPaths": ["/Users/yourname/Pictures/example.png"],
  "finderDirectory": "/Users/yourname/Pictures",
  "workingDirectory": "/Users/yourname/Pictures",
  "invocationIndex": 1,
  "invocationCount": 1
}
```

`finderDirectory` 在 Finder 没有提供目录时省略。手动测试使用文件选择面板所在目录。
逐个执行时，`paths` 只有当前项目，`allPaths` 包含整个选择，调用序号从 1 开始。

工作目录可以选择：选中的文件夹 / 文件所在目录、Finder 当前目录，或指定目录。
多选且选择「全部执行一次」时优先用共同父目录，没有共同父目录则使用 Finder 当前目录。
逐个执行时会为每个输入分别计算工作目录。

## 环境变量与密钥

在脚本页展开「环境变量」，添加脚本需要的配置。变量名不能重复，也不能使用 `RIGHTKIT_` 前缀。

勾选「密钥」的值存入 macOS 钥匙串，共享配置中只保留引用。保存后密钥框会清空：
留空会保留原值，填写新值会替换它，删除变量并保存会移除旧密钥。复制动作后需重新填写密钥。
应用仅在明确执行动作时读取已保存的密钥，打开 Finder 菜单不会读取钥匙串。

日志会遮盖与密钥值完全匹配的文本，包括跨输出块的值；不要让脚本输出编码、截断或变形后的凭据。
普通环境变量会明文保存在配置中，因此令牌、密码和带签名的 URL 应勾选「密钥」。

## 动作市场与导入

在自定义动作窗口切换到「动作市场」，通过右上角的「市场设置」添加或编辑市场网址，再浏览和搜索动作。
也可以在网页点击「在 RightKit 中打开」直接预览动作。

导入预览分为动作说明、源代码和历史版本，可以先检查运行依赖与升级日志。
点击「导入为草稿」后配置本机解释器、工作目录和环境变量，手动测试并保存；保存后才会更新 Finder 菜单。
打开网页链接、下载动作包和导入草稿都不会执行脚本。

市场动作会记录来源和版本。「检查市场更新」打开对应来源，刷新后可通过「仅看可更新」查找新版本。
更新同样先进入草稿，保留本机配置，并根据上次导入版本合并本地修改。
「导入独立副本」生成新的本地动作，之后不参与原动作的更新。

「复制动作包」可将本地动作导出到市场后台的 JSON 编辑器；密钥值和本机路径不会随包导出。
完整规则、市场发布流程和本地联调见 [市场与导入指南](MarketIntegration.md)。

## 运行与排错

- Finder 点击在后台执行；从「设置 → 自定义动作」进入，查看运行日志或停止任务。
- 最多同时运行 3 个任务，保留本次应用会话最近 20 条记录；退出后清空日志记录。
- stdout 和 stderr 各保留前 256 KB，之后继续接收并丢弃超出部分，避免脚本因管道堵塞卡住。
- 超时可设为 1–3600 秒，默认 120 秒，计入整个逐项执行任务。任一调用失败后停止后续调用。
- 停止、超时和正常退出应用会终止脚本进程组，并清理普通子进程。脚本应等待自己的工作完成，
  不要自行 daemonize、创建新会话或启动脱离进程组的后台服务。
- 停止不会撤销已经发生的文件变更或上传；被强制终止的脚本也不保证能执行自己的清理逻辑。
- `ModuleNotFoundError`：在动作所选的 Python 环境中安装对应依赖。
- 命令找不到：检查实际可执行路径或设置 PATH，GUI 应用不会继承终端里的 alias / shell 函数。
- 文件访问被拒绝：查看脚本错误输出。自定义脚本访问受 macOS 保护的位置时仍受系统权限约束；
  RightKit 不会预先请求权限或更改系统隐私设置。

## 配置与执行边界

配置保存在 App Group 下的 `CustomActions/actions.json`，图标位于 `CustomActions/Icons/`。
最多 100 个动作，每个脚本最多 256 KB，每个动作最多 64 个变量、每个值最多 16 KB，单次选择最多 1000 项。
配置采用版本化 JSON 和原子保存；无法读取的配置不会被编辑器自动覆盖。

Finder 扩展只读取菜单描述，不执行脚本，也不读取外部脚本文件或密钥。
点击时写入一次性请求，通过 `rightkit://custom?ticket=<UUID>` 唤起主应用；主应用领取请求，
重新检查动作和选择，再调用与手动测试相同的执行服务。请求有效期为 120 秒，用过即删除。
普通网页不能仅凭动作名称或文件路径拼一个 URL 就执行已保存的脚本。
